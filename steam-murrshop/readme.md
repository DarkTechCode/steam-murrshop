# Steam MurrShop Viewer

Легкая версия Chrome расширения для страниц игр Steam.

## Функции

- Добавляет верхнюю кнопку поиска игры на pplati.ru.
- Показывает в кнопке поиска число предложений plati.market и минимальную цену (через pplati.ru/api.php, кэш 12 ч).
- На страницах игр, недоступных в регионе («Данный товар недоступен в вашем регионе»), показывает кнопку поиска plati с числом предложений в начале страницы; название игры берётся через зеркало Steam API MurrShop.
- Добавляет верхнюю кнопку просмотра игры на murrshop.ru.
- Проверяет наличие игры через публичный endpoint MurrShop.
- Показывает цену MurrShop в верхней кнопке и в блоке `.murrshop-price-block`.
- Показывает рекордную цену при наличии поля `best_market_price`.

## Отличия от steam-murrshop

- Нет popup-окна.
- Нет API-токена.
- Нет очереди импорта.
- Нет добавления или обновления игр на murrshop.ru.
- Нет истории операций.

## Структура

- `manifest.json` - конфигурация расширения.
- `content.js` - вставка кнопок и блока цены на страницу Steam.
- `content.css` - стили кнопок и блока цены.
- `background.js` - проверка игры через MurrShop API и счётчик предложений pplati.ru.
- `icon*.png` - иконки расширения.
